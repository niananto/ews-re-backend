# Early Warning System For River Erosion [BackEnd]

Clone or pull the repo and then run these commands to get the backend running.

```
>npm install
>npm run dev
```

Find the admin site at http://localhost:8080/admin

## Environment Variables

Create a `.env` file with -
```
PORT=
ADMIN_USERNAME=
ADMIN_PASSWORD=
DB_URI=<postgres>
FIREBASE_STORAGE_BUCKET=
```

For Firebase Admin SDK authentication, place your service account key at `sa-key.json` in the project root.
